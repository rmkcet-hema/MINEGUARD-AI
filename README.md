# MINEGUARD AI

## AI-Powered Underground Mine Safety & Rescue Rover

MINEGUARD AI is an intelligent underground mine safety and rescue rover designed to assist rescue teams in hazardous underground environments.

### Key Features

- Real-time person detection
- Fire and smoke detection using YOLO
- Environmental monitoring
- Ultrasonic obstacle detection
- Autonomous obstacle avoidance
- Live rover camera feed
- Real-time monitoring dashboard
- ESP32-based sensor integration

### Technology Stack

- Python
- Streamlit
- YOLO11
- OpenCV
- ESP32
- Ultrasonic Sensors
- DHT22
- MPU6050

### System Overview

Camera → AI Detection → Dashboard

ESP32 Sensors → Dashboard

Ultrasonic Sensors → Obstacle Detection → Rover Navigation
